# نظام محاسبة محل التوابل والبهارات والمكسرات

نظام محاسبة كامل يعمل محلياً على جهازك (بدون إنترنت وبدون أي قاعدة بيانات SQL).
كل البيانات تُحفظ تلقائياً في ملف واحد: `data/db.json`.

## طريقة التشغيل

يحتاج فقط تثبيت [Node.js](https://nodejs.org) على الجهاز (مرة واحدة).

```
node server.js
```

بعدها افتح المتصفح على:

```
http://localhost:3000
```

اترك الطرفية (terminal) شغالة طول فترة استخدام البرنامج. لإيقاف السيرفر اضغط `Ctrl+C`.

> ملاحظة: كل تعديل (منتج، عملية بيع، سعر صرف، عملية مع مورد...) يُحفظ تلقائياً فور حدوثه
> في ملف `data/db.json` — لا حاجة لأي زر "حفظ" عام، ولا حاجة لأي تنصيب قاعدة بيانات.
> يُفضّل نسخ هذا الملف احتياطياً بين فترة وأخرى (Backup) لأنه يحوي كل بيانات المحل.

## المزايا

- **المنتجات**: إضافة صنف باسمه، تصنيفه، كميته، سعر الشراء بالدولار، وسعر بيع اختياري (يمكن تركه فارغاً وتحديده لاحقاً من قائمة المنتجات).
- **سعر الصرف اليومي**: من لوحة التحكم تدخل سعر الدولار مقابل الليرة كل يوم، ويُستخدم تلقائياً لحساب سعر البيع بالليرة لكل الأصناف دون تعديلها واحداً واحداً.
- **البيع (نقطة البيع)**: اختر الصنف، وبِع إما بالكمية (مثلاً 300 غرام) أو بالمبلغ (مثلاً الزبون دفع 1000 ليرة) — والنظام يحسب تلقائياً الكمية المباعة، المبلغ، والربح، وينقص الكمية من المخزون.
- **الموردون**: لكل مورد "دفتر حساب" مستقل — تسجيل عمليات الشراء منه (بالتفصيل حسب الصنف والسعر)، وتحديد إن كان الدفع نقدياً أو آجلاً أو دفعة جزئية، وتسجيل الدفعات (الأقساط) اللاحقة، مع عرض المبلغ المتبقي المستحق له تلقائياً.
- **التقارير**: تقرير يومي وأسبوعي لمجموع المبيعات والأرباح.
- **الطباعة**: طباعة قائمة الأصناف — تختار هل تظهر الأسعار أم لا، وبأي عملة (دولار أو ليرة)، وأي تصنيف.

## بنية البيانات

كل البيانات محفوظة بصيغة JSON بسيطة داخل `data/db.json` (منتجات، موردين، مبيعات، أسعار الصرف اليومية) — يمكن فتح الملف بأي محرر نصوص أو نسخه للاحتفاظ بنسخة احتياطية.
